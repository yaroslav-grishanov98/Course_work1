# Проект приложения для анализа банковских операций 
## Описание:
Данный проект создан для реализации приложения в котором можно анализировать банковские операции

## Установка: 
1. Клонируйте репозиторий:
git clone ///
2. Установите зависимости:
pip install -r requirements.txt
## Использование:
python src/main.py --page main --date 2025-04-15

# Пример использования:
python src/main.py --page events --date 2025-04-15 --period M

**Тесты**:

* Тест вызова скрипта для страницы main
* Тест вызова скрипта для страницы events

### Функция with_cache
Кэширует результаты функции на указанное время

**Тесты**:

* Тест кеширует результат и не вызывает исходную функцию повторно в течение времени жизни кеша

### Функция load_transactions
Загружает транзакции из Excel-файла. Если файл отсутствует или содержит ошибки, создаёт и сохраняет тестовые данные

**Тесты**:

* Тест cоздает пробный DataFrame с транзакциями

### Функция filter_transactions_by_month
Фильтрует транзакции с начала месяца по указанную дату

**Тесты**:

* Тест фильтрации транзакций по месяцу


### Функция get_greeting
Определяет приветствие в зависимости от времени суток

**Тесты**:

* Тест определение приветствия в зависимости от времени

### Функция load_user_settings
Загружает пользовательские настройки из JSON-файла `user_settings.json`

**Тесты**:

* Тест загрузки пользовательских настроек

### Функция get_currency_rates
Получает курсы валют через внешний API с кешированием

**Тесты**:

* Тест получения курсов валют

### Функция get_stock_prices
Получает текущие цены на акции через yfinance или возвращает демо-данные

**Тесты**:

* Тест получения цены акций

### Функция filter_transactions_by_period
Фильтрует транзакции по указанному периоду (неделя, месяц, год, все данные)

**Тесты**:

* Тест фильтрации транзакций по разным периодам

### Функция get_card_info
Получение информации о карте (последние 4 цифры, сумма расходов, кэшбэк)

**Тесты**:

* Создаёт тестовый DataFrame с транзакциями для использования в тестах
* Проверяет корректность работы функции получения информации о картах

### Функция get_top_transactions
Получает транзакций по сумме платежа

**Тесты**:

* Проверяет функцию получения топ транзакций по сумме платежа

### Функция generate_main_page_response
Генерирует json ответ для главной страницы

**Тесты**:

* Проверяет корректность данных ответа главной страницы

### Функция get_expenses_income_data
Анализирует расходы и доходы из транзакций

**Тесты**:

* Проверяет анализ расходов и доходов по транзакциям

### Функция generate_events_page_response
Генерирует JSON-ответы для страницы события

**Тесты**:

* Проверка корректности данных ответа страницы событий для разных периодов
